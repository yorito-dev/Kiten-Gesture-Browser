# Kiten Gesture Browser 0.2.0-preview.3

Windows 11 x64向け公開アルファの変更点です。ミニプレイヤーと分割表示の復元、ブックマークと閲覧履歴の管理、Workspaceのファイル操作を改善しました。

更新前にKitenを終了し、大切なデータをバックアップしてください。実行用ZIPは新しい空フォルダーへすべて展開し、展開先のTabBrowser.exeを起動します。

## 0.2.0-preview.2からの変更

### YouTubeミニプレイヤーと動画再生

- 一時停止した動画が小さく描画される問題を修正しました。最小化したプレイヤーは、動画の表示を隠してから休止します。
- タイトル帯をドラッグしている間も帯を表示します。動画面や操作帯のCtrl＋左ドラッグによるサイズ変更は、左ボタンを押したままCtrlだけを離してEscを押すと元に戻せます。
- 長時間のライブ配信でも、表示中の動画の再生位置からライブ端への到達を判断します。
- 長押しの倍速操作中に広告が始まったときは、広告後に同じ動画へ戻り、新しい速度操作がなく長押し時の速度が残っている場合に元の速度へ戻します。画質メニューでは手動で選んだ画質を識別しやすくしました。
- 縦横比が異なるプレイヤーを整列するとき、最も小さくなる動画の表示面積を優先します。
- 公開版のローカル動画は、動画末尾で再生ボタンを押すと先頭から再開します。
- 状態ファイルが壊れた場合は、読めるバックアップから復元します。起動時に対応するウィンドウがなかったプレイヤーも記録に残し、ほかのプレイヤーの状態を保存して終了できます。

### タブ、ブックマーク、閲覧履歴

- 分割表示の読み込みに失敗した場合や、ペインが開く前にタブを閉じた場合は、元のペアを戻せるときに復元します。分割の状態をバックアップから復元した場合も、起動時の復元が終われば保存を再開できます。
- ブックマーク管理と新しいタブのブックマーク欄で、直前の削除を取り消せます。新しいタブの右クリックメニューから削除できます。
- 閲覧履歴に30日・90日・365日の保持期限を設定できます。設定時に対象件数を確認でき、履歴画面からデータベースの空き領域も整理できます。サイト単位の削除では、絞り込みに含まれる履歴だけを削除するか、サイトの履歴全体を削除するかを選べます。
- 選択した文字列の翻訳結果を、Kitenの閲覧履歴、最近使った項目、セッションなどの保存対象から除きました。
- 埋め込みページの入力欄へ貼り付けできるようにしました。無効な検索URLを使おうとした場合は理由を表示します。
- 閉じたウィンドウのタブをプレビューするとき、元のページを表示します。終了直前に変更したページ倍率も保存します。
- タブの音声をWindows側で左右に振り分ける機能は、利用者が設定で許可してから動作します。左右を設定済みのタブを復元した場合は、設定場所を一度案内します。

### Workspace、FolderTab、ファイル操作

- Workspaceで実ファイルをコピー中も画面を操作できます。ブラウザーのウィンドウを一つ閉じる場合は、そのウィンドウが開始したコピーと結果の保存を待ちます。
- 実ファイルやフォルダーの参照先を画面の操作と並行して確認します。コピー先の内容が変わっているなど、安全を確認できない場合はコピーの取り消しを保留します。
- Workspaceの実ファイル操作で子メニューが白くなる問題を修正しました。整列ボタンの無効表示もダーク配色に揃え、カードがキャンバスに収まらない全体整列は中止します。
- FolderTabで自動更新が起きた場合も検索とプレビューを保持します。上段のアドレス欄へ入力したフォルダーが見つからない場合は理由を表示します。
- 「最近使った項目」で新しく取得する画像を小さくしました。プライベートウィンドウから明示的にWorkspaceへ保存する内容は、終了後も残ることを画面で案内します。

### ダウンロード、拡張機能、設定

- 同梱の.NET RuntimeとSQLiteをセキュリティ修正版に更新しました。
- 複数のダウンロードの保存先を順番に選べます。ダウンロード元のタブを閉じると対応する保存先ダイアログも閉じます。中止したダウンロードの表示が遅れて届いた通知で切り替わる問題を修正しました。Windowsの予約名や危険な拡張子を含むファイル名の扱いも見直しました。
- Chrome・Edgeから新規に取り込んだ拡張機能を、選択したコンテナの管理領域へコピーします。拡張機能のアイコンや設定は選択タブのコンテナに対応します。
- サイト権限の管理画面で、選んだコンテナの保存済み権限を確認し、対応する項目を既定に戻せます。
- マウスジェスチャー設定で未割り当ての方向を選べます。設定の保存と各ウィンドウへの反映を順番に処理し、終了時には保存の完了を待ちます。
- バックアップ・復元の保守ツールでは、処理の取り消しと更新結果が分からない場合を分けて案内します。
- 起動時の案内がブラウザーの背面に隠れる問題を修正しました。導入・更新、同梱バックアップ、既知の制約の案内を本版に合わせました。

## 配布と確認方法

- Windows 11 x64向けの未署名Previewです。配布時は実行用ZIPと同名のSHA-256ファイルを確認してください。
