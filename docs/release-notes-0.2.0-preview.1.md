# Kiten Gesture Browser 0.2.0-preview.1

Windows 11 x64向けの公開アルファ版です。ミニプレイヤー一覧を中心に、現在の開発成果をまとめました。

更新前にKitenを終了し、大切なデータをバックアップしてください。実行用ZIPは新しい空フォルダーへすべて展開して使います。

## 主な変更

- ミニプレイヤー一覧が独立ウィンドウになり、ブラウザー本体を最小化しても操作できます。タイトルバーをダブルクリックすると一覧と見出しだけの表示を切り替え、位置や表示状態も次回起動時に復元します。
- タイトル・余白のクリックによる選択、全選択・全解除、選択行への一時停止・ミュート・閉じるを追加しました。まとめて操作と整列は、チェックがあれば選択分、なければ全件を対象にします。
- 整列は予告を見てから適用でき、Escで予告を取り消せます。閉じた動画は履歴から選んで復元できます。
- 操作結果を一覧にも表示し、5秒後はアクティブな動画のタイトルへ戻します。行の印と、情報バーからその行への移動で対象を確認できます。
- 個別メニューの前面表示・再読み込み、ミュート表示、音量Popupのミュート切替とホイール調整を追加しました。未読込の間は±10秒・速度ボタンを無効にし、操作できる条件を案内します。
- 一覧の高さ・タイトル表示・最前面切替・子メニュー操作・ライブ位置への一括移動・一時視聴の復元を改善しました。

詳しくは[変更履歴](https://github.com/yorito-dev/Kiten-Gesture-Browser/blob/main/CHANGELOG.md)と[導入ガイド](https://github.com/yorito-dev/Kiten-Gesture-Browser/blob/v0.2.0-preview.1/docs/getting-started.md)を参照してください。

## ダウンロード

実行する場合は`Kiten-Gesture-Browser-0.2.0-preview.1-win-x64.zip`を選び、同名の`.zip.sha256`で確認してください。GitHubの「Source code」は開発者向けで、そのまま実行するものではありません。

ローカル動画はWindows標準のMediaElement方式です。対応形式はWindowsのコーデック環境に依存します。実行ファイルは従来どおり未署名です。
