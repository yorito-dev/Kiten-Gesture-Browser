# Kiten Gesture Browser 0.2.0-preview.2

Windows 11 x64向けの公開アルファ版です。空きスペースや指定範囲へのミニプレイヤー整列が使えます。タブ、プライバシー、Workspaceの動作を改善しました。

更新前にKitenを終了し、大切なデータをバックアップしてください。実行用ZIPは新しい空フォルダーへすべて展開し、展開先のTabBrowser.exeを起動します。

## 0.2.0-preview.1からの変更

### YouTubeミニプレイヤーの整列と表示

- 「空きスペース」では、選んだ画面上の他のアプリや整列対象外のプレイヤーを避けて配置します。「指定した範囲」では、マウスで囲んだ枠の中に配置します。複数画面をまたいで範囲を指定できます。
- ドラッグ中の枠の描画を軽くしました。マウスを離した位置で範囲を確定し、適用またはキャンセルまで破線を表示します。
- 指定後は整列メニューへ戻ります。動画が収まらない場合は理由を表示します。空きスペースの横一列では、動画ごとに必要な幅を確保します。
- 「余白なし」を追加しました。すべての整列方式で固定の余白を省きます。グリッドは映像の縦横比を維持し、各プレイヤーをできるだけ大きく並べます。
- 横一列・縦一列で配置位置をクリックすると、その位置を固定します。別の位置にマウスを重ねても予告は変わりません。
- 「調整」「配置案に戻す」「キャンセル」「適用」を整列メニューにまとめました。調整中もメニューを保持し、枠に重なったメニューはドラッグで移動できます。
- 整列後、一覧の結果表示または整列メニューから、直前の配置を1回分戻せます。従来の「最初の整列前へ戻す」も使えます。
- ライブ配信の視聴者数が5桁以上のときに、ミニプレイヤーの表示が途中で切れる問題を修正しました。
- ミニプレイヤーとライブチャットから外部サイトを開く操作は、所有元と同じコンテナのタブで開きます。ミニプレイヤーとチャットでのダウンロードや権限の要求を制限しました。

### ページ表示、タブ、ブックマーク

- ページ側が始めた移動では、ページが切り替わるまで、現在のページのURLと接続状態を表示します。中断した場合も元のページの証明書表示を保持します。
- 埋め込み部分の障害で親ページまで読み直すことを防ぎました。URLのコピーには既存の再試行を使います。
- 縦タブの検索欄を隠すと絞り込みも解除し、検索欄を再表示すると入力済みの条件を使えます。
- ブックマーク管理を開いたままブラウザーを閉じるとき、編集を保存してから閉じます。保存できなかった場合は閉じる操作を中止します。
- 入力処理、タブのドラッグ、ウィンドウ終了中に一部の処理が失敗した場合の後片付けを改善しました。
- 保存が完了していることを確認できる場合は、Windowsの終了を許可します。

### プライバシーとコンテナ

- リンク先プレビューは初期状態で無効です。有効にした場合、新しいタブのブックマークプレビューは通常のタブから分離したInPrivateプロファイルで表示します。
- 「最近使った項目」へのWeb・YouTube閲覧の記録は初期状態で無効です。閲覧履歴とは別の設定で、以前保存した項目はそのまま使えます。
- 閲覧履歴の除外サイトはサブドメインにも適用されます。検索条件を素早く変えたときも、最新の条件の結果を使います。
- ウィンドウをまたぐタブ候補、タブ棚、ミニプレイヤーの一覧と一括操作は、通常・プライベートの区分が同じウィンドウを対象にします。
- コンテナ設定を読み込めない場合でも、タブのコンテナ割り当てを保持します。設定画面には、バックアップを表示中か、コンテナを編集できないかを表示します。
- コンテナを削除する直前に、ほかのウィンドウや閉じたタブで使われていないか確認します。設定画面でコンテナ一覧を更新しても、閲覧履歴から除外するチェックを保持します。
- 一部のセッション復元エラーで、診断にURLのクエリとフラグメントが残らないようにしました。

### Workspace、FolderTab、ダウンロード

- ごみ箱へ移動できない項目は元の場所に残し、移動できなかった件数をお知らせします。
- 別ドライブへコピー・移動するとき、更新日時と対応するファイル属性を保持します。転送中にタブを閉じたり、別のウィンドウへ移したりした場合の終了処理も改善しました。
- メモを編集した状態で閉じると、保存するか確認します。対象のメモだけを読み込むようにしました。
- タブ棚の非同期操作が失敗した場合の処理を改善しました。状態が変わった項目だけを更新します。
- FolderTabの一覧表示では、ファイルの列挙時に取得済みの情報を再利用します。Windowsのアイコン取得が長引く場合も、種類別のアイコンや簡易表示を使えるようにしました。
- ダウンロードがウイルス検出で中断された場合は、理由を表示します。

### 安定性、動作の軽さ、ガイド

- 裏タブを休止する際の表示の扱いを修正し、閉じたタブの休止に失敗した場合はWebView2を解放します。
- Workspaceでカードを削除したときの描画層の再作成を減らし、フォルダー切り替えなどで不要になった描画層を解放します。
- Windowsのスリープ・休止中の時間を、アプリの無応答時間の判定から除外しました。
- ミニプレイヤーの復元・チャット・操作メニュー・終了処理などの内部構造を整理しました。
- 導入・更新、バックアップ、制約、プライバシーの説明を今回の版に合わせました。

## 配布と確認方法

- Windows 11 x64向けの未署名Previewです。実行用ZIPと同名のSHA-256ファイルを確認してください。
