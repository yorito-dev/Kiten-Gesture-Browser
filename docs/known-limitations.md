# Kiten 0.1.0-preview.5 既知の制約

## ローカル再生の対応環境

この配布版のローカル動画・音声の再生には、当面WPF標準のMediaElementを使います。QuickLook、ローカル動画ミニプレイヤー、既存ミニプレイヤー内でのローカル動画再生に対応し、YouTubeはWebView2で再生します。LibVLC・LibVLCSharp・VLCプラグインや付属データは、配布用ZIPに含めていません。

再生の可否はWindowsの再生機能・コーデック・ファイル内容に依存します。WebM、MKV等を含め、選択できる拡張子すべての再生を保証しません。再生できない場合は画面のエラーを記録し、既定アプリでの表示を使えます。追加コーデックや再生エンジンを自動導入しません。

再生、一時停止、シーク、音量、ミュート、速度、ループ、A-Bリピート、ズーム・パン、遅延復元の操作窓口と保存形式を維持します。シークプレビューもWPF標準のMediaPlayerで用意しますが、フレーム到着通知がないためシーク後に有限時間だけ待って取得します。実画面での表示や取得位置は環境により異なる場合があります。すべてのコーデックやGPUでの再生を確認したものではありません。

この文書は0.1.0-preview.5の既知の制約を示します。すべての利用環境で問題が発生しないことを保証するものではありません。

## Prime Videoなど動画サイトの再生

この配布版には、Prime Video向けの互換処理と、動画の再生に失敗したときに互換モードで読み込み直す処理を含めていません。このため、Prime Videoやそのほかの動画サイトで再生できない場合があります。再生の失敗を検出した場合は、表示される案内から、Edgeコンパクト表示（Edgeが利用できない場合は既定のブラウザー）で同じページを開けます。すべての再生失敗を検出できるとは限りません。この配布版での実際の再生可否は未確認です。

## 対応環境

- この版の検証対象はWindows 11 x64だけである。Windows 10、Arm64、x86は未検証である。
- .NET Runtimeは実行用ZIPに同梱している。Webページの表示に使うMicrosoft Edge WebView2 Evergreen Runtimeは、Windows 11には通常、最初から入っている。
- 実行ファイルはコード署名されていないため、Windowsの警告が出る場合がある。
- スマート アプリ コントロールが有効なPCでは、未署名のため起動できない場合がある。無効化による回避は案内しない。[初回起動時の案内](getting-started.md#警告画面が出たとき)を確認する。

## Webページと表示支援

- KitenはWebView2を使うため、Webサイト側の仕様、ログイン制限、地域制限、DRM、WebView2の対応範囲の影響を受ける。
- この配布版には、ChatGPTの表示調整、5ch実況向け表示、X整形モードは含まれていない。これらのサイトは通常のWebページとして表示される。
- リンク先プレビューは専用InPrivateプロファイルで取得するため、通常タブやコンテナでログイン済みでも、その認証を必要とする画像が得られない場合がある。初期状態は有効で、リンク先への通信が発生し得る。`設定`の`一般`→`動作`から無効にできる。
- Chrome／Edgeの完全な代替や、Chrome拡張機能の完全互換は対象外である。展開済み拡張機能はWebView2が対応する範囲に限られる。
- YouTubeミニプレイヤーは、YouTube側の画面の作りが変わると、一時的に正しく動作しなくなる可能性がある。
- 動画ミニプレイヤーは、長時間利用後のGPUまたはWebView2状態によって黒画面が再発する可能性がある。個別の再読み込みまたは開き直しが必要になる場合がある。
- Windowsの表示倍率100%／125%間でミニプレイヤーの操作パネルが離れる問題は修正済みで、利用者も改善を報告した。全モニター構成は未確認である。Webページのズーム率とは区別する。

## 保存、更新、復元

- 実行ファイルを別フォルダーへ移しても、同じStableチャンネルのデータは`%LOCALAPPDATA%\TabBrowser`のままであり、自動分離されない。
- 自動更新はない。更新前に全Windowとミニプレイヤーを終了し、手動バックアップと別の空フォルダーへの展開が必要である。
- 基本バックアップは暗号化されない。WebView2プロファイル、Cookie、認証情報、プライベート一時データ、診断ログ、ダウンロード済み実ファイル、外部ファイル、Webサイト側データは含まれない。
- 更新前バックアップへ戻すと、そのバックアップ作成後の変更は戻らない。未知の新しいデータ形式を旧版へ推測で復元しない。
- 破損した現在データから正常バックアップへ復元するときは、管理対象の破損原本をバイト単位で復旧領域へ残す。破損原本へのROLLBACKは開始前のバイト列を戻すだけで、利用可能な正常データへの回復を保証しない。
- 内容破損と、容量不足・I/O・ロック・アクセス不能・未対応形式は区別する。後者が一つでもある場合は破損原本救済へ読み替えず、現在データを変更せず停止する。
- 中断復旧のROLLBACKは実際に使用する原本を再検証して作業コピーを作ってから開始する。原本またはjournalが変化・欠落している場合はmarkerを保持して停止し、自動修復や推測復元は行わない。
- Workspace DB version 2を使う版から旧版へ戻す場合、旧EXEだけを上書きしない。更新後の現在データを別途保全し、更新前に作成した互換性のある旧形式バックアップを復元してから戻す。
- 名前付き復元点は通常Windowのタブセッション用で、Workspace全体、メモ、Cookie、認証情報、ページ内部状態を戻す世代バックアップではない。
- バックアップ／復元は単体テストと一時データで検証済みだが、実ユーザーデータ、電源断、OSクラッシュ、物理媒体故障での復旧は未確認である。
- WorkspaceのコピーUndoは、対象ファイルの内容ハッシュも照合する。対象数10,000件、合計内容64 MiBの確認上限や読取不能、内容変更等で安全を確認できない場合、実ファイルを取り除かずUndoを保留する。照合から実操作までの外部プロセスとの競合を完全に排除する保証ではない。

## プライベートWindow

- プライベートWindowは専用の一時WebView2領域を使い、通常のセッション、履歴、閉じたタブ、ダウンロード履歴、ミニプレイヤー状態を保存しない。
- ダウンロードした実ファイルや、利用者が明示的にWorkspaceやブックマークへ保存した内容は残る。
- 終了時に一時領域の削除を試みるが、OSやWebView2がファイルを保持している場合は削除が遅れ、次回起動時の再試行までローカルに残る可能性がある。

## 公開・報告

- 通常の不具合と非公開の脆弱性報告は専用アドレス`kiten.gesture.contact@gmail.com`へ送る。診断情報は自動送信しない。詳細は[不具合報告ガイド](../REPORTING.md)を確認する。
- 同梱の`release-info.json`／`package-manifest.json`の`publicationStatus`／`publicReleaseEligible`は、生成ツールが記録する生成時点の内部状態で、公開後も`not-published`／`false`のまま残ります。配布物の確認にはReleaseページのSHA-256を使ってください。
